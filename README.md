## 🪟 Windows Debugger

Учебный low-level отладчик для Windows x86/x64, разработанный для изучения внутреннего устройства исполняемых файлов, отладочных механизмов ОС и расширения отладочных инструментов через плагины и скрипты.

Проект поддерживает работу с 32- и 64-битными процессами, аппаратные и программные точки останова, пошаговую трассировку, инспекцию и изменение памяти/регистров, дизасемблирование, логирование, а также удобный интерфейс на базе Dear ImGui.

Отдельное внимание уделено работе с PE-файлами и символами: вместо сырых адресов можно использовать имена символов, включая полные имена и относительные записи вида `symbol!module.dll`.

### ✨ Основные возможности

- **Поддержка x86 / x64**  
  Работа с 32- и 64-битными Windows-процессами.

- **Точки останова**  
  Поддерживаются как программные, так и аппаратные breakpoints.

- **Пошаговая трассировка**  
  Реализована через плагинную архитектуру.

- **Плагины**  
  Собственный интерфейс расширений для добавления отладочной функциональности.

- **Python-биндинги**  
  Возможность управлять отладчиком и писать скрипты на Python.

- **Работа с памятью и регистрами**  
  Команды для чтения, записи и анализа состояния процесса.

- **Дизасемблирование**  
  Просмотр инструкций по адресам или символам.

- **ImGui-интерфейс**  
  Графический интерфейс на базе Dear ImGui.

- **Логирование**  
  Журналирование отладочных событий и действий.

- **Поддержка PE и символов**  
  Можно указывать символы вместо адресов:
  - полные имена символов;
  - относительные символы вида `symbol!module.dll`.

###  Технологии

- C / C++
- WinAPI
- x86 / x64 assembly
- PE format
- Python bindings
- Dear ImGui
- Plugin architecture

### ⚠️ Назначение

Проект носит образовательный и исследовательский характер. Предназначен для анализа собственных или явно разрешённых бинарных файлов.
