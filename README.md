## 🪟 Windows PE Debugger

Учебный low-level проект: собственный отладчик и загрузчик PE-исполняемых файлов для Windows.

Проект посвящён изучению внутреннего устройства Windows-бинарников и низкоуровневой отладки:

- разбор PE-структур: DOS header, NT headers, секции, импорты/экспорты;
- работа с процессами, потоками, памятью и контекстом CPU через WinAPI;
- базовые отладочные механизмы: точки останова, обработка исключений, инспекция регистров и памяти;
- низкоуровневая разработка на C/C++;

> ⚠️ Проект носит образовательный характер и предназначен для анализа собственных или явно разрешённых бинарных файлов.

**Stack:** C / C++ / MASM32 / WinAPI / PE format  
**Platform:** Windows
